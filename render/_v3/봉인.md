## 무엇을 그리나

**12칸 트랙 체계의 옛 문안을 그린다.** HEAD 렌더러는 이걸 못 그린다.

```
옛 문안   면 = { 번호 · 제목 · 메타 · 행[] · 실무확인 }      행 → 열(폭) → 블록 → 내용
새 문안   면 = { 번호 · 제목 · 모드 · 카피 · 논지 · 골격 · 자리[] }

content/sokcho/실행계획서.json          18쪽   ← 여기
content/gangneung/홍보전략브리프.json     13쪽   ← 여기
content/sokcho/사업장운영시뮬레이션.json    8쪽   ← 여기
content/_check/폭조절.json                    ← 여기
content/_check/판면기준.json            14쪽   HEAD 렌더러 전용
```

표 · 목록 · 번호목록 · 수치 · 단계띠 · 지도 · 표지를 **여기만 안다.**

## 쓰는 법 · `--v3` 깃발

```sh
node scripts/build.js     content/sokcho/실행계획서.json --v3
node scripts/roundtrip.mjs content/sokcho/실행계획서.json --v3
```

깃발이 없으면 HEAD 렌더러로 간다. 옛 문안에 깃발을 빠뜨리면 이렇게 죽는다.

```
Error: 구성에 띠가 없다
```

옛 표지 면의 `구성` 을 새 엔진이 「골격 덮어쓰기」로 읽어서다. **뜻이 두 시대에서 다르다.**
