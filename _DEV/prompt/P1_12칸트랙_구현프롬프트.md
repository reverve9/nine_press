## §0 역할

판면 격자의 눈금을 3칸에서 **12칸**으로 잘게 한다. **실폭은 바뀌지 않는다** — 눈금만 잘아진다.
단 하나 예외가 `실행계획서 p.21 첫 행`이고, 그것은 의도된 교정이다(§3 Q4).

**이 프롬프트의 범위 밖을 건드리지 않는다.**

## §1 작업 범위

### 1-1. `rules/page.css` **맨 끝**에 덧붙임

```css
/* ────────────────────────────────────────────────────────────
   ㉗ 12칸 트랙  (2026-08-19)

   앞 규칙 `.row.g>.col,.row.g>.b` 의 계수를 4로 나눈 것이다.
   폭 1 · 1.5 · 2 · 3  →  칸 4 · 6 · 8 · 12.  실폭은 그대로다.

     4칸 = 693.99   6칸 = 1055.49   8칸 = 1416.98   12칸 = 2139.98

   함께 `.row.g` 제한을 푼다.
   `.g` 는 면의 마지막 행에만 붙으므로, 마지막이 아닌 행은 트랙을 안 타고
   flex 비율 + 블록 안쪽 여백이 섞인 값으로 나뉘고 있었다.
   실측에서 실행계획서 p.21 첫 행이 그 이유로 37.60px 어긋나 있었다.

   특정도를 `.page` 로 올려 앞 규칙(0,3,0)과 동률로 만들고 뒤에서 덮는다.
   세로 채움 규칙 `.row.g{flex:1}` 은 건드리지 않는다.
   ──────────────────────────────────────────────────────────── */
.page .row>.col, .page .row>.b{
  flex:0 0 calc((92.739*var(--w,4) - 14.879)*var(--u))!important;
  min-width:0;
}
```

### 1-2. `render/index.js` — 기본 칸 수 둘

| 행 | 지금 | 후 |
|---|---|---|
| 205 `renderBlock` 인자 | `폭 = 1` | `폭 = 4` |
| 224 `renderCol` | `const 폭 = col.폭 ?? 1;` | `const 폭 = col.폭 ?? 4;` |

**다른 곳은 손대지 않는다.** `flex:${폭}` 인라인 값은 CSS `!important` 가 이기므로 그대로 둔다.

### 1-3. `content/sokcho/*.json` — 판면 열의 폭에 4를 곱한다

**문자열 치환으로 한다. `json.dump` 로 재직렬화하지 않는다** — 들여쓰기가 바뀌어 diff 가 전 파일로 번진다.

```
정규식   "폭"\s*:\s*(\d+(?:\.\d+)?)      →  값 × 4
```

표 열의 폭은 `"26%"` 처럼 **문자열**이라 이 정규식에 걸리지 않는다. 확인했다.

**치환 전후 분포 — 이 값이 나와야 한다**

| 파일 | 전 | 후 |
|---|---|---|
| `실행계획서.json` | `1`×50 · `1.5`×8 · `2`×2 · `3`×4 | `4`×50 · `6`×8 · `8`×2 · `12`×4 |
| `사업장운영시뮬레이션.json` | `1`×22 · `2`×1 · `3`×11 | `4`×22 · `8`×1 · `12`×11 |

합계 98개. **소수가 남으면 안 된다.**

### 1-4. `app/ui/Shell.jsx` — 구조 편집의 폭 상수

| 행 | 지금 | 후 |
|---|---|---|
| 45 | `열: [{ 폭: 1, …` | `폭: 4` |
| 225 | `a + (c.폭 ?? 1)` | `?? 4` |
| 229 | `{ 열: [{ 폭: 3, …` | `폭: 12` |
| 238 | `if (폭합(행) >= 3)` | `>= 12` |
| 239 | `{ 폭: 1, 블록: […] }` | `폭: 4` |
| 249 | `if (나머지 + w > 3)` | `> 12` |
| 417 | `?.폭 ?? 1) : 1` | `?? 4) : 4` |
| 446 | `{[1, 2, 3].map((w) =>` | `{[3, 4, 6, 8, 9, 12].map((w) =>` |

**51행의 표 열 `폭: '50%'` 은 문자열이다. 건드리지 않는다.**

안내 문구 두 곳도 함께 고친다.

```
'한 행의 폭 합은 3을 넘지 않는다'  →  '한 행의 칸 합은 12를 넘지 않는다'
```

`열 폭` 이라는 라벨(444행)은 **`칸 수`** 로 바꾼다.

### 1-5. `scripts/save.sh` — 경로 인자를 받는다

P0-b 커밋에 세션 시작 전부터 남아 있던 미커밋분 32개가 함께 실렸다. 앞으로 경로를 주면 그것만 담게 한다.

**주석 사용법**

```sh
#   sh scripts/save.sh "메시지"                       작업 트리 전체
#   sh scripts/save.sh "메시지" render/index.js …     준 경로만
```

**본문** — `MSG` 를 읽은 직후

```sh
MSG=${1:-"작업 저장 $(date '+%Y-%m-%d %H:%M')"}
[ $# -gt 0 ] && shift

if [ $# -gt 0 ]; then
  git add -- "$@"
else
  git add -A
fi
```

기존 `git add -A` 한 줄을 위 블록으로 갈음한다. **나머지 줄은 그대로 둔다.**

## §2 금지 사항

| | |
|---|---|
| ① | **`rules/page.css` 의 앞 블록을 고치지 않는다.** 끝에 덧붙이기만 한다 |

| ⑦ | **드래그 · 폭 끌기 · 이미지 · 변형 고르기에 미리 손대지 않는다.** P2 이후다 |
