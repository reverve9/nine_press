## §0 역할

**판면 규칙과 렌더러를 키노트 세팅 기준으로 다시 쓴다.** 12칸 트랙 체계를 버리고 · 골격 목록 체계로 간다.

**기존 `rules/page.css` 1028줄과 `render/index.js` 332줄을 버리고 새로 쓴다.** 둘 다 `_legacy/v3/` 에 백업돼 있고 커밋 `544ea70` 에 들어 있다. 되살릴 일이 생기면 거기서 가져온다.

**이번 블록은 편집기를 건드리지 않는다.** `app/ui/Shell.jsx` 는 그대로 둔다. 새 렌더러로 미리보기가 깨지는 것은 예상된 결과이고 · 편집기 대응은 B 갈래에서 따로 한다.

## §1 작업 범위

### 1-1 `rules/page.css` 신규 작성

**기존 파일을 지우고 처음부터 쓴다.** 옛 블록(① ~ ㉚)을 옮겨 오지 않는다.

담을 것.

```
판 · 안전 영역 · 본문 프레임 · 헤더 · 푸터 밴드
색 7 · 선 굵기 · 안쪽 여백 변수
글자 3계층 (라벨 · 제목 · 문단) — 나머지 6계층은 N3
영역 배치 규칙 (좌표는 렌더러가 인라인으로 준다)
```

**좌표 계산을 CSS 에 넣지 않는다.** 옛 파일이 `calc()` 로 트랙을 만들다가 함정 ②③④ 를 다 밟았다. **이번에는 렌더러가 정수 좌표를 계산해 인라인 `style` 로 박고 · CSS 는 모양만 맡는다.**

### 1-2 `render/index.js` 신규 작성

**함수 인터페이스를 바꾸지 않는다.** `scripts/build.js` · `scripts/pdf.js` · `app/` 라우트가 그대로 물린다.

```
export function renderPage(page, doc = {})
export function render(doc, { css, cssBase = '../../rules', 도구: 표식 = false } = {})
export default render
```

`render/inline.js` 는 **그대로 쓴다.** 고치지 않는다.

담을 것.

```
split()  가로 정수 분할 · §3-4 알고리즘 그대로
rows()   세로 정수 분할 · §3-5
골격 표  G1 ~ G12 · §3-6
면 렌더  헤더 · 카피 · 논지 · 블록 존 · 푸터
블록 렌더 라벨 · 제목 · 문단 셋만
```

### 1-3 검사용 문안 `content/_check/판면기준.json` 신규

**골격 열둘을 한 번씩 쓰는 12면 + 모드 검사 2면 = 14면.** 내용은 골격 이름과 좌표를 적은 더미로 충분하다.

### 1-4 `rules/fonts.css` 는 그대로 둔다

### 1-5 `scripts/build.js` 는 손대지 않는다

그림 base64 치환은 N4 에서 다시 본다. 이번에는 건드리지 않는다.

### 3-4 가로 정수 분할

**키노트 세팅 `split()` 을 그대로 옮긴다. 고치지 마라.**

```js
function split(start, total, n, g){
  const w=(total-g*(n-1))/n, end=start+total, p=[], out=[];
  for(let i=0;i<n;i++) p.push(Math.round(start+i*(w+g)));
  for(let i=0;i<n;i++) out.push({x:p[i], w:(i<n-1? p[i+1]-g-p[i] : end-p[i])});
  return out;
}
```

**경계를 반올림하고 폭을 경계에서 역산한다.** 합이 언제나 정확히 2179 다.

**2:1 · 1:2 는 3열에서 병합한다.** 별도 계산식을 만들지 마라.

```
2:1   좌 x80 w1438 · 우 x1561 w698      split(80,2179,3,43) 의 [0]+[1] 병합
1:2   좌 x80 w698  · 우 x821  w1438      [1]+[2] 병합
```

### 3-5 세로 정수 분할

```js
function rows(t, h, ratio, g=43){        // ratio : '1:1' | '1:2' | '2:1'
  const [a,b] = ratio.split(':').map(Number);
  const first = Math.round((h-g) * a/(a+b));
  return [{y:t, h:first}, {y:t+first+g, h:h-g-first}];
}
```

**세로 비율은 `1:1` · `1:2` · `2:1` 셋으로 잠정 고정한다.** 실측 뒤 늘릴 수 있다.

### 3-7 문안 데이터 형식

```json
{
  "문서명": "판면 기준 검사",
  "서식": "제안서",
  "여백": 33,
  "면": [
    {
      "번호": "01",
      "제목": "G3 · 3열",
      "모드": "카피",
      "카피": { "메인": "...", "서브": "..." },
      "논지": "...",
      "골격": "G3",
      "자리": [ { "라벨": "...", "제목": "...", "문단": ["...", "..."] } ]
    }
  ]
}
```

```
모드      "카피" | "연속"
골격      G1 ~ G12
자리      골격이 만든 영역 순서대로 채운다. 순서는 띠 → 열 → 박스
여백      문서 기본값 33. 블록에 "여백": n 을 주면 그 블록만 덮어쓴다
비율      골격 기본값을 덮어쓰려면 면에 "비율" 을 준다
          { "띠": "1:2", "열": [null, "2:1"] }
```

**골격에 없는 구성이 필요하면 `골격` 대신 `구성` 을 직접 준다.**

```json
"구성": { "띠": [ { "비율": 1, "열": [ {"박스":1}, {"박스":1}, {"박스":2} ] } ] }
```

**`자리` 개수가 골격이 만든 영역 수와 다르면 오류를 던지고 멈춘다.** 조용히 넘기지 마라.
