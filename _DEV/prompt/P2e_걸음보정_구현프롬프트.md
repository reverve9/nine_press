## §0 역할

**격자 좌표와 끌기 감도를 트랙 산식에 맞춘다.** 둘 다 앞 프롬프트를 쓴 쪽의 잘못이고, 보고한 진단이 정확했다.

**틀린 자리는 하나다** — `92.73975` 를 **칸 폭**으로 오해했다. 그 값은 **걸음(칸 + 거터)** 이다.

```
트랙 산식   폭(w) = (92.73975 · w − 14.879) · u
            92.73975 = 걸음        −14.879 = 마지막 거터를 덜어냄
```

| | 값 | px |
|---|---|---|
| 걸음 | `92.73975 · u` | **180.749** |
| 칸 폭 | `(92.73975 − 14.879) · u` | **151.750** |
| 거터 | `14.879 · u` | 29.000 |

**실측 대조** — `content/_check/폭조절.json` 면01

```
4칸  = 4×180.749 − 29 = 693.996      실측 693.98
8칸  = 8×180.749 − 29 = 1416.99      실측 1416.98
12칸 = 12×180.749 − 29 = 2139.99     .bd 폭 2139.97
칸4의 left = 4×180.749 = 722.996     실측 722.97
```

**이 프롬프트의 범위 밖을 건드리지 않는다.**

## §1 작업 범위 — `app/ui/Shell.jsx` 두 자리

### 1-1. 격자 좌표 (452–457행 부근)

```
지금   c.style.left  = (k * (92.73975 + 14.879) * uu) + 'px';
       c.style.width = (92.73975 * uu) + 'px';

후     c.style.left  = (k * 92.73975 * uu) + 'px';
       c.style.width = ((92.73975 - 14.879) * uu) + 'px';
```

지시값으로는 12번째 띠가 `.bd` 를 **348px** 넘고 띠 폭이 거터를 먹는다.

### 1-2. 끌기 걸음 (`칸너비` 선언 · 409행 부근)

```
지금   const 칸너비 = (92.73975 + 14.879) * uu;   // 209.76
후     const 칸너비 = 92.73975 * uu;              // 180.75
```

**근거** — 칸을 하나 늘릴 때 경계가 옮겨지는 거리는 `d(폭)/d(칸) = 92.73975 · u` 다. 열 개수가 그대로라 거터 수도 그대로이므로 거터가 한 번 더 붙지 않는다.

주석도 함께 고친다.

```js
const 칸너비 = 92.73975 * uu;   // 한 칸 걸음 = 판면 180.75px · 축척 30% 에서 화면 약 54px
```
