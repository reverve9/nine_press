## §0 역할

**N1-b 보고의 둘을 닫는다. N2 를 깨끗한 바닥에서 시작하기 위한 정리 블록이다.**

```
① 06면(G6) 더미 글자가 교체 전 좌표를 달고 있다
② 최상위 function r(v) 가 지역 r 에 두 곳에서 가려진다
```

**②가 이 블록의 이유다.** 지금은 아무 일도 안 일어나지만 · N2 는 도형 · 구분선이라 그 블록 안에 좌표 반올림이 들어갈 여지가 크다. 들어가는 순간 `r(...)` 이 사각형 객체를 함수로 부르는 꼴이 되어 조용히 터진다. **N2 착수 전에 없앤다.**

**이 블록은 이름 하나와 문자열 셋만 건드린다.** 로직을 바꾸지 마라.

## §1 작업 범위

### 1-1 `render/index.js` · 최상위 `r` 를 `반올림` 으로 바꾼다

**바꾸는 줄은 셋이다.**

```
47   function r(v) {                                    → function 반올림(v) {
60   p.push(r(start + i * (w + g)));                    → p.push(반올림(start + i * (w + g)));
69   const first = r((h - g) * a / (a + b));            → const first = 반올림((h - g) * a / (a + b));
```

**지역 `r` 은 그대로 둔다.** 아래 다섯 줄은 손대지 마라.

```
126  const r = 비율.띠 ?? ...           띠 비율 문자열
140  const r = 비율.열?.[ci] ?? ...     열 비율 문자열
162  function 블록(자리, r, i, 여백문서)  사각형 객체
164  left:${r.x}px ...                  사각형 객체
201  rects.map((r, i) => 블록(...))     사각형 객체
```

**최상위 이름이 `반올림` 이 되면 가려질 일이 없다.** 지역 이름을 바꾸느라 diff 를 키우지 마라.

### 1-2 `content/_check/판면기준.json` · 06면 문자열 셋을 고친다

**06면(`"번호": "06"` · `"골격": "G6"`) 의 자리 3 · 자리 4 만이다. 다른 면을 건드리지 마라.**

```
자리 3 · 문단[0]
  "가로 x1191 w513 → 1704"      →  "가로 x1191 w512 → 1703"

자리 4 · 제목
  "x1747 · y567"                →  "x1746 · y567"

자리 4 · 문단[0]
  "가로 x1747 w512 → 2259"      →  "가로 x1746 w513 → 2259"
```

**자리 3 의 제목 `"x1191 · y567"` 은 이미 맞다. 건드리지 마라.**
**자리 1 의 `"가로 x80 w513 → 593"` 도 이미 맞다. 건드리지 마라.**

**문안을 통째로 재생성하지 마라.** 문자열 셋만 바꾼다. 재생성하면 자리 개수 · 골격 · 모드 · 14면 첫 자리의 `"여백": 66` 시험까지 함께 흔들릴 수 있다.

### 1-3 그 외 어떤 파일도 고치지 않는다

`rules/page.css` · `render/inline.js` · `scripts/*` · `app/*` 전부 그대로다.

## §2 금지 사항

| | 무엇 |
|---|---|
| ① | **`반올림()` 의 본문 로직을 고치지 마라.** 짝수 쪽 반올림 그대로다 |
| ② | **`split()` · `rows()` 의 다른 줄을 고치지 마라** |
| ③ | **지역 `r` 다섯 자리를 바꾸지 마라.** §1-1 목록 참조 |

| ⑤ | **N2 요소를 미리 넣지 마라.** 구분선 · 도형 · 그림자 · 모서리 반경 전부 다음 블록이다 |
| ⑥ | **`app/ui/Shell.jsx` · `render/inline.js` 를 건드리지 마라** |
| ⑦ | **`next build` 를 돌리지 마라 · dev 서버에 붙지 마라** |
| ⑧ | **`git` 을 직접 쓰지 마라.** `sh scripts/save.sh "메시지" <경로들>` 만 쓴다 |
| ⑨ | **`—` 를 쓰지 마라.** 구분자는 `:` `\|` `→` `·` |

## §3 착수 전 확정 사항

**전부 확정값이다. 사용자에게 되묻지 마라.**

### 3-1 이름

```
최상위 반올림 함수    반올림
```

**이 레포는 이미 `존높이` · `열자리` · `영역` · `블록` 으로 한글 식별자를 쓴다.** 결에 맞고 · 한 글자 지역 변수와 절대 겹치지 않는다.

### 3-2 이번 블록이 판면 좌표에 주는 영향

```
없다. 한 칸도 움직이지 않는다.
```

**이름 교체는 동작이 같고 · 문안 보정은 더미 글자라 렌더 좌표에 안 닿는다.** §4 관문에서 좌표가 하나라도 달라지면 그건 교체 실수다.

### 3-3 06면 인라인 좌표가 정답이다

```
인라인 좌표(실제)   x1191 w512 → 1703  ·  x1746 w513 → 2259     맞다
더미 글자(옛 값)    x1191 w513 → 1704  ·  x1747 w512 → 2259     이걸 고친다
```

**글자를 좌표에 맞춘다. 좌표를 글자에 맞추지 마라.**
