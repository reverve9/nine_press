## §1 작업 범위

### 1-1. ⓐ `rules/page.css` ㉗ 블록 — 계수 한 개

```
지금   92.739   * var(--w,4)
후     92.73975 * var(--w,4)
```

**해당 줄만 고친다.** 주석과 나머지 선언은 그대로 둔다.

**근거** — 원 계수 `370.959` 를 4로 나눈 정확한 값이 `92.73975` 다.

| 칸 | 92.739 | **92.73975** | 원래 값 |
|---|---|---|---|
| 4 | 693.9941 | **693.9999** | 693.9999 |
| 6 | 1055.4907 | **1055.4995** | 1055.4995 |
| 8 | 1416.9873 | **1416.9990** | 1416.9990 |
| 12 | 2139.9806 | **2139.9981** | 2139.9981 |

챗 세션이 컨테이너에서 재렌더해 확인했다. 정밀값으로 바꾸면 **실행계획서 p.01 · p.12 의 픽셀 차이가 0 으로 떨어진다.**

주석에 한 줄을 덧붙인다.

```
   계수는 370.959 / 4 = 92.73975.  소수 3자리로 자르면 12칸에서 0.0175px 이 깎인다.
```

### 1-2. ⓑ `app/ui/Shell.jsx` 248행

```
지금   const 나머지 = 폭합(행) - (행.열[P.ci].폭 ?? 1);
후     const 나머지 = 폭합(행) - (행.열[P.ci].폭 ?? 4);
```

**지적이 옳다.** P1 §1-4 표에서 빠뜨렸다. 같은 성격의 기본값이다.

`app/ui/Shell.jsx` 안에 **다른 `?? 1` · `?? 3` · `> 3` · `>= 3` 이 남아 있는지 전수로 훑고**, 판면 열의 폭을 다루는 것이면 함께 고친다. 표 열의 폭(문자열 `%`)과 무관한 곳은 건드리지 않는다.

### 1-3. ⓒ `scripts/save.sh`

**지금 (P1 지시분)**

```sh
MSG=${1:-"작업 저장 $(date '+%Y-%m-%d %H:%M')"}
[ $# -gt 0 ] && shift

if [ $# -gt 0 ]; then
  git add -- "$@"
else
  git add -A
fi
```

**교체본**

```sh
MSG=${1:-"작업 저장 $(date '+%Y-%m-%d %H:%M')"}

if [ $# -gt 1 ]; then
  shift
  git add -- "$@"
else
  git add -A
fi
```

**지적이 옳다.** 인자가 0개면 `[` 가 1을 반환하고 AND 리스트 전체가 비0 이 되어 `set -e` 가 그 자리에서 스크립트를 끝낸다. 조건문 맥락이 아니라 면제되지 않는다.

교체본은 `shift` 를 `if` 안으로 넣어 그 경로를 없앤다.

| 호출 | 동작 |
|---|---|
| `sh scripts/save.sh` | 전체 |
| `sh scripts/save.sh "메시지"` | 전체 |
| `sh scripts/save.sh "메시지" a b` | `a` · `b` 만 |
