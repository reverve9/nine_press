## §1 지금 판이 어떻게 서 있나

### 1-1 도크 탭 넷 · **층이 섞여 있다**

```
판면    페이지에 걸린다      레이아웃 · 모드 · 칸 수
박스    고른 박스에 걸린다    배경 · 투명도 · 테두리 · 굵기 · 모서리 · 그림자 · 글자
요소    고른 요소에 걸린다    목록 · 순서 · 놓기 · 갈래별 편집 · 요소 도형(일곱)
얹기    페이지에 걸린다      선 · 도형 · 그림 · 글 + 각자의 자리와 꼴
```

**사용자 판정 · 이건 두 무리다.**

```
그릇     판면(골격) + 박스(꼴)          박스가 몇 개 생기나 · 그 박스가 어떻게 생겼나
내용     놓기(요소) + 얹기              무엇을 담나
```

### 1-2 놓기와 얹기는 **대등하다** · 사용자 판정

```
놓기   제목 · 요약 · 문단 · 목록 · 번호목록 · 표 · 수치 · 빈칸 · 비움 · 출처 · 그림    열하나
얹기   선 · 도형 · 그림 · 글                                                  넷
```

**다른 것은 하나뿐이다.**

```
놓기   자리를 흐름이 정한다     순서대로 쌓인다 · 앞이 길어지면 뒤가 밀린다
얹기   자리를 내가 정한다       판 절대 좌표 · 안 밀린다
```

겹치는 어휘가 둘 있다 · **그림은 양쪽에 다 있고** · 얹기의 「글」은 놓기의 「문단」과 같은 물건이다.

### 1-3 얹기가 지금 어떻게 도는가

```
데이터    page.얹기[]  ·  { 선|도형|그림|글, x, y, 폭, 높이, 층 }
층        '뒤'(기본) · '앞'  둘뿐이다 · 박스 기준이다
쌓임      같은 층 안에서는 배열 순서 = DOM 순서
자리      놓을 때 고른 박스 안쪽 사각형에서 시작한다 (7c852e2)
자석      Shift · 박스 모서리 · 거터 한가운데 · 글만 42 기준선도
```

`render/index.js` 의 쌓임 차례는 이렇다.

```
.hd 제목  →  .cp 카피  →  .tt 요지  →  얹기층('뒤')  →  박스들 .bx  →  얹기층('앞')  →  .ft 푸터
```

## §2 이번에 지을 것

### 2-1 도크를 두 탭으로 재편한다

```
[판]     판면      레이아웃 열둘 · 카피 영역 있다/없다 · 칸 수 갈래      지금 것 그대로 옮긴다
         박스      배경 · 투명도 · 테두리 · 굵기 · 모서리 · 그림자 · 글자 · 비움

[내용]   층 목록    §2-2
         놓기      갈래 고르기 + [박스 안] / [판 위] 스위치
         고른 것    지금 요소 탭 · 얹기 탭의 편집 판을 갈래에 따라 낸다
```

**「박스 안 / 판 위」 스위치 하나가 놓기와 얹기의 유일한 차이를 그대로 드러낸다.**
그림도 `그림 · 박스 안` / `그림 · 판 위` 로 한 자리에 선다.

### 2-2 층 목록 · **데이터는 안 바꾼다**

내용이 대등해졌으니 **겹칠 수 있다.** 그러면 무엇이 위인지를 볼 자리가 있어야 한다.

```
층 · 위가 앞

  글    "축제앱을 새로 짓지 않는다"          얹기 · 층 앞
  도형                                   얹기 · 층 앞
  ═══ 박스 ═══                            박스와 그 안 요소가 통째로 여기 든다
  선                                     얹기 · 층 뒤
  도형  배경                               얹기 · 층 뒤
```

```
끌어 올리고 내린다        같은 층 안에서는 배열 순서가 바뀐다
「박스」 칸막이를 넘기면    층이 앞 ↔ 뒤로 바뀐다
박스를 고르면            칸막이 자리에 그 박스의 요소 목록이 펼쳐진다 (흐름 순서 · 쌓임 아님)
```

**데이터는 지금 그대로다** · `층: '앞'|'뒤'` + 배열 순서. UI 만 한 목록으로 합친다.
숫자 층을 새로 만들지 마라 · 렌더러 계약이 바뀌면 봉인본 회귀가 깨진다.

### 2-3 라벨 정리 · 사용자가 표로 넘긴다

우패널 라벨 75개를 표로 뽑아 두었다 · 사용자가 고칠 이름을 적어 넘긴다.
**앞 세션에서 셋을 이미 반영했다.**

```
「박스를 고른다」 삭제                             0b8e6f5
「내용이 든 박스 N개가 빠진다 · 그만」 삭제 · 못 고르게 막음   0b8e6f5
얹기 기본 자리를 고른 박스로                        7c852e2
```

**아직 안 정한 것 둘.**

```
얹기 갈래 「도형」이 두 뜻이다      + 도형 으로 놓는 사각형  vs  배경 · 테두리 · 모서리 · 그림자
                              얹기에서만 겹친다 · 이름을 갈라야 한다
도형 일곱이 세 곳에 있다          박스 탭 · 요소 탭 · 얹기 도형 · 한 부품으로 묶는다
                              얹기에만 「글자」가 없다 · 이제 글이 생겼으니 필요하다
```

```

빈 상태 문구     안 띄운다 · 「박스를 고른다」를 되살리지 마라
```

## §4 금지 사항

| | 무엇 |
|---|---|
| ① | **렌더러 계약을 바꾸지 마라** · 얹기 층을 숫자로 넓히지 마라 · 이번은 도크만이다 |

| ⑤ | **`git` 을 직접 쓰지 마라** · `sh scripts/save.sh "메시지" <경로들>` 만 쓴다 |
| ⑥ | **`—` 를 쓰지 마라** · 구분자는 `·` `\|` `→` `:` |
