## §0 역할

**다른 사업의 문서 하나를 nine_press 로 올리기 위해 렌더러를 넓힌다.**

올릴 문서 — 「오세인 · 강릉 홍보전략 브리프」 13쪽. 판면 규격(2339×1654 · `--u`)은 같고 색과 크기만 다르다.

**넷을 더한다.**

| | 무엇 | 지금 |
|---|---|---|
| ① | 블록 **제목**(`.bt`) | 라벨로 흡수되어 있다. CSS 는 `page.css:46` 에 살아 있다 |
| ② | 인라인 **형광**(`==글자==`) · **배지**(`[[글자]]`) | 없다 |
| ③ | 단계띠 **줄 모양**(`.tl`) | `.fl` 한 가지뿐 |
| ④ | 위 표기의 **왕복 복원** | `원문()` 두 곳 |

**배경 `fill` `nv` `gr` 는 CSS 에 이미 있다. 렌더러도 `b.배경` 을 그대로 클래스로 붙이므로 손댈 것이 없다.**

**이 프롬프트의 범위 밖을 건드리지 않는다.** 판면 변종 CSS 와 데이터 변환은 챗 세션이 따로 한다.

## §1 작업 범위

### 1-1. `render/index.js` · `renderBlock` — 라벨과 제목을 가른다

**현재 (211–214행 부근)**

```js
  // 블록 머리는 라벨 하나다 (§7 판정 ⑤ — .bt 폐기).
  // 옛 문안의 `제목` 은 라벨로 받아 준다.
  const 머리 = b.라벨 ?? b.제목;
  if (머리) o.push(`<div class="bl"${dp(P && [...P, '라벨'])}>${inline(머리)}</div>`);
```

**교체본**

```js
  // 블록 머리는 둘이다. 라벨(작은 대문자 띠) 위, 제목(.bt) 아래.
  // 둘 다 선택이고 한쪽만 써도 된다. 속초 문안에는 `제목` 이 하나도 없어 렌더가 안 바뀐다.
  if (b.라벨) o.push(`<div class="bl"${dp(P && [...P, '라벨'])}>${inline(b.라벨)}</div>`);
  if (b.제목) o.push(`<div class="bt"${dp(P && [...P, '제목'])}>${inline(b.제목)}</div>`);
```

### 1-2. `render/inline.js` — 표기 둘

`{TBD}` 처리 **뒤**, `**굵게**` 처리 **앞**에 넣는다.

```js
    // ==글자== → 형광. [[글자]] → 배지. [[!글자]] → 강조 배지
    .replace(/==(.+?)==/g, '<span class="hl">$1</span>')
    .replace(/\[\[(!?)([^\]\n]+)\]\]/g,
      (_, im, x) => `<span class="tg${im ? ' im' : ''}">${x}</span>`)
```

주석 머리의 표기 목록에도 두 줄을 더한다.

```
//   ==형광==        → <span class="hl">  형광펜
//   [[배지]]        → <span class="tg">   · [[!배지]] 는 강조
```

### 1-3. `render/index.js` · `단계띠` — 줄 모양

**현재 (110–117행 부근)**

```js
function 단계띠(v, P) {
  const 칸 = v.칸 ?? [];
  return '<div class="fl">' + 칸.map(([d, t], i) =>
    `<div class="st${i === v.현재 ? ' on' : ''}">` +
    `<div class="sd"${dp(P && [...P, '단계띠', '칸', i, 0])}>${inline(d)}</div>` +
    `<div class="sm"${dp(P && [...P, '단계띠', '칸', i, 1])}>${inline(t)}</div></div>`).join('') +
    '</div>';
}
```

**교체본**

```js
// 모양:"줄" 이면 가로 축 타임라인(.tl). 현재까지의 칸이 전부 .k 로 찍힌다.
// 기본(.fl)은 현재 칸 하나만 .on 이다.
function 단계띠(v, P) {
  const 칸 = v.칸 ?? [];
  const 줄 = v.모양 === '줄';
  const 겉 = 줄 ? 'tl' : 'fl';
  const 속 = 줄 ? 't' : 'st';
  return `<div class="${겉}">` + 칸.map(([d, t], i) => {
    const 표시 = 줄 ? (i <= v.현재 ? ' k' : '') : (i === v.현재 ? ' on' : '');
    return `<div class="${속}${표시}">` +
      `<div class="${줄 ? 'd' : 'sd'}"${dp(P && [...P, '단계띠', '칸', i, 0])}>${inline(d)}</div>` +
      `<div class="${줄 ? 'n' : 'sm'}"${dp(P && [...P, '단계띠', '칸', i, 1])}>${inline(t)}</div></div>`;
  }).join('') + '</div>';
}
```

### 1-4. 왕복 복원 — `원문()` 두 곳

**`scripts/roundtrip.mjs`** 와 **`app/ui/Shell.jsx`** 의 `원문()` 은 **같은 규칙이어야 한다.** 두 곳 다 고친다.

`.tbd` 처리 **바로 뒤**에 넣는다.

```js
      if (cl?.contains('hl')) { s += '==' + 원문(n) + '=='; continue; }
      if (cl?.contains('tg')) {
        s += '[[' + (cl.contains('im') ? '!' : '') + n.textContent + ']]';
        continue;
      }
```

**`.tg` 는 `textContent` 로 읽는다.** 배지 안에는 표기를 넣지 않는다.

## §2 금지 사항

| | |
|---|---|
| ① | **`rules/page.css` 를 건드리지 않는다.** 판면 변종은 챗 세션이 따로 낸다 |
| ② | **`content/**` 를 건드리지 않는다** |

| ⑤ | `.fl` 기본 동작을 바꾸지 않는다. `모양` 이 없으면 지금 그대로다 |
| ⑥ | `next build` 를 돌리지 않는다 |
| ⑦ | `git` 명령을 직접 쓰지 않는다. **`sh scripts/save.sh "메시지" <경로들>`** 만 쓴다 |

| | 확정값 |

## §5 관문 — 통과 못 하면 보고하고 멈춘다

### 5-1. 왕복 — 값이 그대로여야 한다

```
node scripts/roundtrip.mjs content/sokcho/실행계획서.json
node scripts/roundtrip.mjs content/sokcho/사업장운영시뮬레이션.json
```

**`검사 1040개 · 불일치 0개` · `검사 600개 · 불일치 0개`.**
속초 문안에는 `제목` · `==` · `[[` · `모양` 이 하나도 없으므로 렌더 결과가 지금과 같아야 한다.

### 5-2. 산출 HTML 이 그대로인가

```
node scripts/build.js content/sokcho/실행계획서.json --link
node scripts/build.js content/sokcho/사업장운영시뮬레이션.json --link
grep -c "class=\"bt\"\|class=\"hl\"\|class=\"tg\|class=\"tl\"" out/html/실행계획서.html out/html/사업장운영시뮬레이션.html
```

**둘 다 `0`.**

### 5-3. 새 표기가 실제로 도는가

아래를 **임시 파일로** 만들어 한 번 돌리고 **지운다.** `content/` 에 남기지 않는다.

```
mkdir -p /tmp/np && cat > /tmp/np/t.json <<'JSON'
{"문서명":"표기 시험","면":[{"번호":"01","제목":"시험","행":[{"열":[{"폭":12,"블록":[
{"라벨":"라벨","제목":"블록 제목","내용":[
{"문단":"보통 글자와 ==형광== 과 [[배지]] 와 [[!강조배지]] 와 **굵게**"},
{"단계띠":{"모양":"줄","현재":1,"칸":[["8월","하나"],["9월","둘"],["10월","셋"]]}}]}]}]}]}]}
JSON
node scripts/build.js /tmp/np/t.json --link
grep -c 'class="bt"' out/html/t.html
grep -c 'class="hl"' out/html/t.html
grep -c 'class="tg"' out/html/t.html
grep -c 'class="tg im"' out/html/t.html
grep -c 'class="tl"' out/html/t.html
grep -c 'class="t k"' out/html/t.html
```

**기대값** — `1 · 1 · 1 · 1 · 1 · 2`. 마지막이 2인 것은 `현재:1` 이라 0번과 1번 칸이 지나온 구간이기 때문이다.

그 뒤 왕복도 돌린다.

```
node scripts/roundtrip.mjs /tmp/np/t.json
```

**`불일치 0개`.** 여기서 어긋나면 §1-4 복원 규칙이 틀린 것이다.

확인이 끝나면 `/tmp/np` 와 `out/html/t.html` 을 지운다.
