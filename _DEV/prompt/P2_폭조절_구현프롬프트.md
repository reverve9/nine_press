## §0 역할

판면에서 **블록 경계를 끌어 열 폭을 조절**할 수 있게 한다.
좌표는 여전히 규칙이 계산한다. 데이터에 남는 것은 **칸 수 정수 하나**뿐이다.

**이 프롬프트의 범위 밖을 건드리지 않는다.** 특히 블록 이동 드래그(P3)에 손대지 않는다.

---

## §1 규칙 — 먼저 읽는다

| | |
|---|---|
| ① | **한 행의 칸 합은 언제나 12 다.** 미만도 초과도 없다 |
| ② | **한 열의 하한은 4칸(694px)이다.** 3칸 이하는 지금 서식으로 못 버틴다 |
| ③ | 경계를 끌면 **왼쪽이 늘고 오른쪽이 준다.** 건드리는 열은 둘뿐이다 |
| ④ | 열 개수는 끌기로 바뀌지 않는다. `열넣기` · `열빼기` 소관이다 |

**②의 근거** — 안쪽 여백 19u 좌우 · 테두리 1px 을 빼면 본문에 남는 폭이 이렇다.

| 칸 | 칸 폭 | 본문 폭 | 한 줄 글자 수 |
|---|---|---|---|
| 3 | 513 | 437 | 약 17 — **표가 2열도 안 선다** |
| 4 | 694 | 618 | 약 24 |

3칸 이하를 쓰려면 작은 활자 · 얇은 여백의 **전용 변형**이 먼저 있어야 한다. **P5 소관이다.**

**하한 4칸에서 나올 수 있는 구성은 이것뿐이다.**

```
1열   12
2열   4+8 · 5+7 · 6+6 · 7+5 · 8+4
3열   4+4+4
```

## §2 작업 범위

### 2-1. `app/ui/Shell.jsx` · `재기()` 안에 경계 손잡이

`재기()` 가 주입하는 도구용 `<style>` 에 아래를 더한다.

```css
.row{position:relative}
.rz{position:absolute;top:0;bottom:0;width:calc(14.879*var(--u));
    margin-left:calc(-7.44*var(--u));cursor:col-resize;z-index:50}
.rz:hover,.rz.on{background:rgba(230,129,0,.22)}
```

`d.body.dataset.집음` 가드 안에서, 이벤트를 붙인 뒤 손잡이를 심는다.

**심는 자리** — 각 `.row` 의 **인접한 두 직계 자식 사이**. 자식이 하나인 행은 건너뛴다.

```
자식 n 개 → 손잡이 n-1 개
i 번째 손잡이의 left = (i 번째 자식의 offsetLeft + offsetWidth) + 거터의 절반
```

손잡이에 `data-rz="<왼쪽 자식 색인>"` 를 단다. 행은 `closest('.row')` 로 찾는다.

**손잡이는 도구 모드에서만 붙는다.** `재기()` 는 앱 안에서만 돌므로 산출 HTML 에는 들어가지 않는다. 그래도 `.page [data-b]` 가 없으면 심지 않도록 한 번 더 막는다.

### 2-2. 끌기

| 단계 | 동작 |
|---|---|
| `mousedown` | 손잡이에 `.on` · 시작 `clientX` · 두 열의 현재 칸 수를 기억 · `document.body.style.userSelect='none'` |
| `mousemove` | 아래 산식으로 칸 이동량을 내고, **두 열의 인라인 `--w` 만 바꿔 미리 보인다.** 데이터는 아직 안 건드린다 |
| `mouseup` | `.on` 해제 · 이동량이 0 이 아니면 `바꾸기(…, { 그리기: true })` 로 확정 |
| `Escape` | 인라인 `--w` 를 원래 값으로 되돌리고 취소 |

**칸 이동량 산식**

```
칸너비 = (92.73975 + 14.879) * u        u = 1.949  →  209.76px … 판면 좌표
이동 = Math.round((clientX - 시작X) / (칸너비 * view))
```

**`view` 를 빼면 안 된다.** iframe 안의 `.page` 에 `transform:scale(var(--view))` 가 걸려 있어 마우스 좌표는 축소된 값이다. `getComputedStyle(d.documentElement).getPropertyValue('--view')` 로 읽는다.

**제약** — 아래를 어기는 이동량은 그 직전 값으로 자른다. 거부 메시지를 띄우지 않는다.

```
왼쪽 칸 + 이동 >= 4
오른쪽 칸 - 이동 >= 4
```

### 2-3. 데이터 반영

```js
바꾸기((d) => {
  const 행 = d.면[면ref.current].행[ri];
  행.열[ci].폭     = 왼쪽 + 이동;
  행.열[ci + 1].폭 = 오른쪽 - 이동;
}, { 그리기: true });
```

**되돌리기 스택에 한 번만 들어간다.** 끄는 도중에는 `바꾸기` 를 부르지 않는다.

### 2-4. 칸 수 칩 — 목록과 동작

**목록을 바꾼다.**

```
지금   [3, 4, 6, 8, 9, 12]
후     [4, 5, 6, 7, 8, 12]
```

`3` 과 `9` 를 뺀다. 하한 4칸에서는 나올 수 없는 값이다.

**동작도 바꾼다.** 지금은 선택 열만 바꿔 합이 12 미만이 될 수 있다. 끌기와 같은 규칙으로 맞춘다.

```
차 = w - 현재 칸
받을 열 = 오른쪽 인접 열, 없으면 왼쪽 인접 열
받을 열의 칸 - 차 < 4  또는  인접 열이 없다  →  거부하고 '칸 합은 12 를 지킨다' 를 로그에 남긴다
```

### 2-5. `열넣기` · `열빼기` — 합 12 를 지킨다

**지금 `열넣기` 는 `폭합(행) >= 12` 면 거부한다. 모든 행이 이미 합 12 라 열을 넣을 수 없다.**

| | 후 |
|---|---|
| `열넣기` | 왼쪽 열(`P.ci`)에서 **4칸을 떼어** 새 열에 준다. 왼쪽 열이 **8칸 미만이면 거부**하고 `'열을 넣으려면 지금 열이 8칸 이상이어야 한다'` 를 로그에 남긴다 |
| `열빼기` | 지운 열의 칸을 **오른쪽 인접 열**에 준다. 오른쪽이 없으면 왼쪽에 준다 |

`행넣기` 는 지금대로 `폭: 12` 한 열이다. 바꾸지 않는다.

### 2-6. 라벨

`칸 수` 옆에 현재 칸과 합을 적는다.

```
칸 수   4 / 12
```

| | |
|---|---|

## §4 착수 전 확정 사항

이 챗 세션에서 이미 판정된 값이다. **질문 없이 그대로 간다.**

| | 확정값 |
|---|---|
| Q1 · 무엇을 끄는가 | **두 열 사이 경계.** 왼쪽이 늘면 오른쪽이 준다 |

| Q5 · 합이 12 미만인 행을 허용하는가 | **아니다.** 언제나 12 다 |
| Q6 · 끄는 도중 실제 재렌더 | **아니다.** 인라인 `--w` 만 바꿔 미리 보이고, 놓을 때 한 번 그린다 |
| Q7 · 하한을 어겼을 때 | **조용히 자른다.** 경고를 띄우지 않는다 |
