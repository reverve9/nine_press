## §0 역할

**N1 보고에서 유일하게 안 넘어간 §5-1 4열을 닫고 · 커밋까지 마친다.**

원인 판정은 끝났다. `split()` 의 `Math.round` 가 `.5` 를 올림 방향으로 고정하는데 · §5-1 표는 짝수 쪽 반올림(키노트 · Numbers 계열)으로 뽑힌 값이다. **표가 기준이고 코드가 따라간다.** N1 프롬프트 §3-4 의 「고치지 마라」는 키노트 세팅을 그대로 옮기라는 뜻이었고 · 키노트의 실제 반올림이 짝수 쪽이었으므로 이 교체가 그 지시를 어기는 게 아니라 완성하는 것이다.

**이번 블록은 이 반올림 하나만 건드린다.** 다른 파일 · 다른 줄에 손대지 마라.

## §1 작업 범위

### 1-1 `render/index.js` 에 반올림 헬퍼 `r()` 를 넣는다

`split()` · `rows()` 바로 위에 둔다.

```js
function r(v){                       // 짝수 쪽 반올림 · half to even
  const f = Math.floor(v), d = v - f;
  if (d > 0.5) return f + 1;
  if (d < 0.5) return f;
  return (f % 2 === 0) ? f : f + 1;
}
```

### 1-2 `split()` · `rows()` 의 `Math.round` 를 `r()` 로 바꾼다

**바꾸는 곳은 딱 두 군데다.** 그 외 어떤 `Math.round` 도 건드리지 마라.

```js
function split(start, total, n, g){
  const w=(total-g*(n-1))/n, end=start+total, p=[], out=[];
  for(let i=0;i<n;i++) p.push(r(start+i*(w+g)));          // Math.round → r
  for(let i=0;i<n;i++) out.push({x:p[i], w:(i<n-1? p[i+1]-g-p[i] : end-p[i])});
  return out;
}

function rows(t, h, ratio, g=43){
  const [a,b] = ratio.split(':').map(Number);
  const first = r((h-g) * a/(a+b));                       // Math.round → r
  return [{y:t, h:first}, {y:t+first+g, h:h-g-first}];
}
```

### 1-3 그 외 어떤 파일도 고치지 않는다

`rules/page.css` · `content/_check/판면기준.json` · `render/inline.js` · `scripts/*` 전부 그대로다.
