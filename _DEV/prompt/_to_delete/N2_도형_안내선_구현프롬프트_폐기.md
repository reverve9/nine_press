# N2 · 도형 속성 묶음 · 안내선 · 보기 토글

작성 2026-08-20 · 레포 `nine_press` · 착수 시점 HEAD `eb132f3`

---

## §0 역할

**블록에 도형 속성을 붙이고 · 미리보기 전용 안내선을 넣는다.**

```
도형    블록 속성 · 배경 · 테두리 · 모서리 · 그림자 · 투명도    출력에 나간다
안내선  칸 경계 · 전역 토글 · 미리보기 전용                     출력에 안 나간다
```

**좌표 체계에 손대지 않는다.** N1 에서 51칸을 맞춰 놨다. 이번 블록이 끝난 뒤에도 51칸이 한 칸도 안 움직여야 한다. §5-1 이 그걸 센다.

**N1 의 방식을 그대로 쓴다.** 도형 값도 렌더러가 만들어 인라인 `style` 에 박고 · CSS 는 모양만 맡는다.

## §1 작업 범위

### 1-1 `render/index.js` · `블록()` 에 도형 속성을 붙인다

**`.bx` 자체에 붙인다. `.bx` 안에 래퍼 `div` 를 만들지 마라.**

이게 이번 블록에서 제일 중요한 한 줄이다. `.bx` 에는 `overflow:hidden` 이 걸려 있는데 · **요소의 `overflow` 는 자손만 자르고 자기 자신의 `box-shadow` 는 안 자른다.** 배경 · 테두리 · 그림자는 요소 자신의 장식이라 clip 대상이 아니다. 실측으로 확인했다.

```
박스 경계  x 150..316 · y 100..246   (overflow:hidden · padding 33 · box-shadow 0 6px 24px)
아래 y248  (170,170,170)      그림자 나온다
오른 x318  (196,196,196)      그림자 나온다
위   y 95  (227,227,227)      그림자 나온다
```

**그런데 `.bx` 안에 `<div class="sh">` 같은 걸 하나 더 깔고 거기에 그림자를 주면 그때는 진짜로 잘린다.** 그래서 래퍼 금지다.

`overflow:hidden` 은 그대로 둔다. 넘침 방어 역할을 겸하고 있다.

### 1-2 인라인 `style` 조립 순서를 고정한다

**기존 좌표 문자열 뒤에 이어 붙인다.**

```
left:{x}px;top:{y}px;width:{w}px;height:{h}px[;padding:{n}px][도형]
```

도형 부분의 순서는 아래로 고정한다.

```
;background:{색}
;border:1px solid {색}
;border-radius:{n}px
;box-shadow:{그림자}
```

**기본값인 속성은 문자열에 넣지 않는다.** 도형을 안 준 자리는 N1-c 와 한 글자도 다르지 않은 `style` 이 나와야 한다. §5-1 이 그걸 센다.

### 1-3 `render/index.js` · 도형 값 해석기와 검사

§3-1 ~ §3-4 의 목록과 규칙 그대로다. 값이 목록에 없으면 오류를 던지고 멈춘다.

### 1-4 `render/index.js` · `doc.판면` 을 `doc.보기` 로 바꾼다

```
옛   doc.판면    문자열 하나가 .wrap 에 통째로 붙는다
새   doc.보기    이름 배열 → 클래스로 매핑
```

**하위 호환을 두지 마라.** `doc.판면` 을 읽는 코드를 지운다. 문안 어디에도 `"판면"` 키를 쓰는 곳이 없는 것을 확인했다.

### 1-5 `rules/page.css` · 안내선 · 반전 글자 · 인쇄 규칙

담을 것.

```
.wrap.gd .bx        안내선
.bx[data-글자="반전"] 아래 글자 3계층 색 반전
@media print 에서 안내선 강제 끔 (도형은 그대로 인쇄된다)
```

**기존 `.dbg` 규칙을 지우지 마라.** 외곽선과 안내선은 쓰임이 다르다. §3-5 참조.

### 1-6 검사용 문안 `content/_check/도형.json` 신규

§3-6 구성 그대로 7면이다.

### 1-7 `content/_check/판면기준.json` 을 건드리지 않는다

**§5-1 회귀 검사의 기준선이다. 한 글자도 고치지 마라.**

## §3 착수 전 확정 사항

**전부 확정값이다. 사용자에게 되묻지 마라.**

### 3-1 도형 데이터 형식

**자리 항목에 `"도형"` 객체를 선택으로 받는다.**

```json
{
  "라벨": "...", "제목": "...", "문단": ["..."],
  "도형": {
    "배경":   "연회색",
    "테두리": "선",
    "모서리": 8,
    "그림자": "약",
    "투명도": 100,
    "글자":   "반전"
  }
}
```

```
배경     이름 또는 #RRGGBB      기본 "없음"
테두리   이름 또는 #RRGGBB      기본 "없음" · 굵기는 1px 고정
모서리   정수 0 ~ 40            기본 0
그림자   이름                   기본 "없음"
투명도   정수 0 ~ 100           기본 100 · 배경에만 건다
글자     "반전" 만              기본 없음
```

**여섯 키 전부 선택이다. `"도형"` 자체가 없어도 되고 · 있어도 일부만 줘도 된다.**

### 3-2 색 목록

**이름이 우선이고 `#RRGGBB` 도 받는다. 그 밖은 전부 오류다.**

```
배경 이름
  없음      transparent      속성을 아예 안 낸다
  흰색      #FFFFFF
  연회색    #F4F6F8          기존 --블록배경
  연파랑    #EAF0F6
  연주황    #FDF2E4
  진네이비  #131B2B          글자 반전이 자동으로 켜진다

테두리 이름
  없음      속성을 아예 안 낸다
  선        #E4E8EC          기존 --선
  강조      #2D4D6E          기존 --강조

그림자 이름
  없음      속성을 아예 안 낸다
  약        0 1px 3px rgba(19,27,43,.10)
  중        0 4px 16px rgba(19,27,43,.14)
```

**자유 hex 는 `^#[0-9a-fA-F]{6}$` 만 통과시킨다.**

세 자리 `#abc` · `rgb(...)` · `red` 같은 CSS 색 이름 · 공백이 섞인 문자열 전부 오류로 멈춘다. **이 값은 `style` 속성 안으로 그대로 들어간다.** 검사를 느슨하게 하면 문안이 판면 규칙을 넘어 임의 CSS 를 밀어 넣는 통로가 된다. 정규식으로 막는다.

### 3-3 투명도는 배경에만 건다

**`opacity` 를 쓰지 마라.** `opacity` 는 자손까지 흐리게 만들어 글자가 같이 죽는다. 인쇄물에서 글자가 흐려지면 안 된다.

**배경색 hex 에 알파 두 자리를 붙여 `#RRGGBBAA` 로 만든다.**

```
알파 = 반올림(투명도 * 255 / 100) 을 두 자리 hex 로 · 대문자
투명도 100 이면 알파를 안 붙인다      #EAF0F6
투명도 40  이면                       #EAF0F666
배경이 "없음" 이면 투명도를 무시한다   오류가 아니다
```

### 3-4 글자 반전

```
배경이 진네이비        자동으로 켜진다
"글자": "반전"         명시로 켠다 · 자유 hex 로 어두운 색을 쓸 때 이걸 준다
그 밖                  안 켜진다
```

**밝기를 계산해 자동 판정하지 마라.** 진네이비 하나만 자동이고 나머지는 명시다. 계산으로 정하면 문안 작성자가 결과를 예측할 수 없다.

렌더러는 `.bx` 에 `data-글자="반전"` 을 붙이고 · 색은 CSS 가 정한다.

```css
.bx[data-글자="반전"] .lb{color:rgba(255,255,255,.72)}
.bx[data-글자="반전"] .bt{color:#fff}
.bx[data-글자="반전"] .bd{color:rgba(255,255,255,.88)}
.bx[data-글자="반전"] b,.bx[data-글자="반전"] .bd b{color:#fff}
```

### 3-5 안내선 · 외곽선 · 보기 토글

**둘은 쓰임이 다르다. 합치지 마라.**

```
외곽선  dbg   검사용 · 대시 · .bx + 헤더 · 카피 · 논지 · 푸터 + 안전 영역
안내선  gd    칸 경계용 · 실선 옅게 · .bx 만
```

```json
"보기": ["외곽선", "안내선"]
```

```
외곽선 → dbg
안내선 → gd
없거나 빈 배열 → <div class="wrap">
배열이 아니면 오류
모르는 이름이면 오류
```

```css
.wrap.gd .bx{outline:1px solid rgba(19,27,43,.14);outline-offset:0}
```

**`outline` 을 쓴다. `border` 를 쓰면 도형의 테두리와 겹쳐 자리를 다툰다.**

**둘 다 인쇄에서 강제로 꺼진다.** `@media print` 의 기존 `dbg` 끔 줄에 `gd` 를 같이 넣는다. **도형은 끄지 마라. 출력에 나가는 물건이다.**

### 3-6 검사 문안 `content/_check/도형.json` 구성

**7면이다. 문서 머리에 `"보기": ["외곽선", "안내선"]` 를 넣는다.**

```
01  G3  배경    연회색 · 연파랑 · 연주황
02  G3  테두리  선 · 강조 · #C8102E
03  G3  모서리  0 · 8 · 24
04  G3  그림자  없음 · 약 · 중
05  G2  투명도  연파랑 100 · 연파랑 40
06  G2  반전    진네이비(자동) · #1B3A5C + "글자":"반전"
07  G6  도형 없음 4칸        회귀 확인용 · style 에 좌표만 나와야 한다
```

모드는 전부 `"카피"` 로 둔다. 내용은 속성 이름과 값을 적은 더미로 충분하다.

**더미 글자에 좌표를 적지 마라.** N1 에서 06면이 그것 때문에 어긋났다. 속성 이름과 값만 적는다.

### 3-7 오류 일곱

**전부 메시지를 달고 멈춘다. 조용히 넘기지 마라.**

```
① 모르는 배경 이름
② hex 형식 위반          #abc · rgb(0,0,0) · red · 공백 섞임
③ 모르는 테두리 이름
④ 모르는 그림자 이름
⑤ 모서리가 정수 0 ~ 40 밖
⑥ 투명도가 정수 0 ~ 100 밖
⑦ 보기가 배열이 아니거나 · 모르는 이름이 들어옴
```

메시지에 **받은 값과 허용 목록을 같이 적는다.** N1 의 오류 메시지들과 결을 맞춘다.

## §5 관문

### 5-1 좌표 회귀 · 이게 제일 중요하다

**빌드 전에 기준선을 뜬다.**

```
cp out/html/판면기준.html /tmp/before.html
node scripts/build.js content/_check/판면기준.json --link
diff /tmp/before.html out/html/판면기준.html
```

**`diff` 가 0 줄이어야 한다.**

판면기준.json 에는 `"도형"` 도 `"보기"` 도 없다. 그러니 산출 HTML 이 **한 글자도** 달라지면 안 된다. 한 줄이라도 나오면 도형 코드가 기본 경로를 건드린 것이다. 커밋하지 말고 보고한다.

`/tmp/before.html` 이 없으면 N1-c 커밋 `eb132f3` 에서 먼저 빌드해 떠 둔다.

### 5-2 도형 인라인 문자열

```
node scripts/build.js content/_check/도형.json --link
```

**`out/html/도형.html` 에서 아래 문자열을 그대로 찾는다.**
