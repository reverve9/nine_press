## 7. 함정 — 이번 세션에서 어시스턴트가 실제로 밟은 것

**다섯 건 전부 사용자 쪽 보고로 잡혔다. 같은 데서 또 넘어지지 마라.**

| | 무엇 | 어디서 |
|---|---|---|
| ① | **`grep` 결과를 `head` 로 자르지 마라.** `page.css` 는 끝에 덧붙이는 구조라 앞부분만 보면 값이 전부 낡은 것이다 | P1 — 격자 수치를 「틀렸다」고 잘못 보고 |
| ② | **계수를 눈대중으로 반올림하지 마라.** `370.959/4 = 92.73975` 를 `92.739` 로 잘라 0.0175px 이 깎였고 서브픽셀 렌더가 달라졌다 | P1-b |
| ③ | **`92.73975` 는 걸음이다.** 칸 폭으로 오해해 거터를 또 더했다. 격자와 끌기가 동시에 어긋났다 | P2-e |
| ④ | **값을 박기 전에 그 값을 덮는 곳을 끝까지 따라가라.** `page.css` 의 `transform:scale(var(--view))` 를 `preview/route.js` 가 끄고 있었다 | P2-b |
| ⑤ | **`set -e` 아래에서 `[ … ] && cmd` 를 단독으로 쓰지 마라.** 조건이 거짓이면 스크립트가 그 자리에서 끝난다 | P1-b |
| ⑥ | 폭 · 칸 수 같은 상수는 **렌더러 · 앱 · 데이터 셋에 흩어져 있다.** 하나를 바꾸면 전수로 훑는다 | P1 — 렌더러 2 · 앱 9 · 데이터 98 |
| ⑦ | **`.bd` 직계에 `.row` 없이 `.b` 가 놓인 문서가 있다.** 강릉 원본이 그랬고 변환기가 블록을 통째로 놓쳤다 | 이관 |
| ⑧ | **전역 `justify-content:space-between` 은 부작용이 크다.** 여백은 사라지지만 넘침이 늘고 라벨이 내용과 벌어진다. 블록별로 건다 | 브리프 판면 |

**v4 §8 함정 ①~⑨ 도 그대로 유효하다.** 특히 ① `device_bash` 로 git 을 돌리지 마라 · ④ JSON 을 통째로 재직렬화하지 마라.

## 8. 검사 절차 — 이번 세션에서 실제로 돌린 것

```
① 로컬   node scripts/build.js <문서>.json --link
② 챗     device_stage_files 로 out/html/*.html 과 rules/*.css 를 함께 올린다
③ 챗     컨테이너에서 npm i playwright  ·  브라우저는 내려받지 않는다
④ 챗     chromium.launch({ executablePath: '/opt/pw-browsers/chromium-1194/chrome-linux/chrome' })
```

**주입 CSS** — 빼면 좌표가 0.42배로 나온다.

```
body{padding:0!important}
.wrap{width:2339px!important;margin:0!important}
.sheet{width:auto!important;height:auto!important;overflow:visible!important;margin:0 0 20px 0!important}
.sheet .page{transform:none!important;margin:0!important}
```

| 재는 것 | 방법 |
|---|---|
| 열 경계 | `.row` 자식의 `offsetLeft` · `offsetWidth` |
| 넘침 | `.bd` · `.col` · `.b` 의 `scrollHeight − clientHeight` |
| 블록 안 빈자리 | `블록 bottom − padding − 마지막 자식 bottom` |
| 고아 줄 | `Range.getClientRects()` 로 줄을 묶고 마지막 줄 폭 비율 |
| 회귀 | 쪽마다 PNG 를 떠서 `numpy` 로 픽셀 대조 |

**이전 상태와 대조하려면 이전 HTML 과 이전 `page.css` 를 한 벌로 보관한다.** 새 CSS 로 옛 HTML 을 렌더하면 판면이 깨진다.

**로컬 Mac 에는 playwright 브라우저가 없다.** `roundtrip.mjs` 는 로컬에서 돌지만 컨테이너 검사는 챗이 한다.

**폰트가 필요하면** `assets/fonts/` 를 stage 해서 `@font-face` 로 물린다. 서브셋은 `pyftsubset` — 강릉 브리프는 533자로 4.4MB → 337KB 였다.
