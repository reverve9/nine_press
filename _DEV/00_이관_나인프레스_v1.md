## 3. 그림 경로 — P4 의 앞부분만 열었다

개발계획 v2 §4 의 P4(이미지) 중 **경로만** 열었다. 맞춤 · 초점은 P4 로 남는다.

| 파일 | 바뀐 것 |
|---|---|
| `render/index.js` | 자리 배열 셋째 칸이 경로. `.sh.on` + `<img class="shi">` |
| `scripts/build.js` | `--link` 는 `../../assets/` · 아니면 base64. 폰트와 같은 방식 |
| `app/api/img/[...p]/route.js` | 신설. `/api/font` 와 같은 구조. `assets/` 밖은 400 |
| `app/ui/Shell.jsx` | 미리보기에서 `src="assets/` → `src="/api/img/` |
| `rules/page.css` | ㉚ `.sh.on`. 경로가 없으면 종전 그대로 |

```json
"자리": ["pc", "접수 목록 화면", "assets/캡처/A1_접수목록.png"]
"자리": ["free", "구조도", "assets/캡처/D1_구조도.svg"]
```

**자리 크기는 안 바뀐다.** 그림은 테두리 2px 뺀 안쪽에 들어간다. 실측 `971.6×546.5` 자리에 `969.6×544.5`.

**비율이 어긋난 그림은 잘린다.** `object-fit:cover` 다. `.pc` 16:9 · `.mo` 9:19.5 · `.free` 는 자리 나름.

**자리 이름은 지우지 않고 숨긴다.** roundtrip 검사 개수를 유지하기 위해서다.

## 6. 함정

**v5 §7 · v4 §8 의 도구 관련 조항은 그대로 유효하다.**

| | 무엇 |
|---|---|
| ① | **`grep` 결과를 `head` 로 자르지 마라.** `page.css` 는 끝에 덧붙이는 구조다 |
| ② | **계수를 눈대중으로 반올림하지 마라.** `370.959/4 = 92.73975` |
| ③ | **`92.73975` 는 걸음이다.** 칸 폭으로 오해해 거터를 또 더하지 마라 |
| ④ | **값을 박기 전에 그 값을 덮는 곳을 끝까지 따라가라** |
| ⑤ | **`set -e` 아래에서 `[ … ] && cmd` 를 단독으로 쓰지 마라** |
| ⑥ | 폭 · 칸 수 상수는 **렌더러 · 앱 · 데이터에 흩어져 있다** |
| ⑦ | **`.bd` 직계에 `.row` 없이 `.b` 가 놓인 문서가 있다** |
| ⑧ | **`device_bash` 로 git 을 돌리지 마라.** `.git/*.lock` 을 못 지운다 |
| ⑨ | **JSON 을 통째로 재직렬화하지 마라.** 다만 `indent=2` + 끝 개행이면 원본과 바이트가 같다. 확인하고 쓴다 |

**이번 세션에서 새로 밟은 것**

| | 무엇 |
|---|---|
| ⑩ | **macOS 파일명은 NFD 다.** `git diff -- content/sokcho/실행계획서.json` 은 pathspec 이 안 걸린다. **디렉터리로 건다** |
| ⑪ | **`device_commit_files` 경로에 한글을 이스케이프로 넣지 마라.** `캡` 을 `캐` 로 잘못 써 빈 폴더가 생겼고 **챗은 폴더를 못 지운다** |
| ⑫ | **`git log -L` 의 「file has only N lines」는 커밋본 기준이다.** 작업본과의 차가 미커밋분이다 |
| ⑬ | **눈대중으로 「크기가 다르다」고 말하지 마라.** 실측이 같았고 캡처 자체의 여백이었다 |

## 7. 검사 절차

**챗 쪽 VM(`device_bash`)에는 playwright 브라우저가 없다.** `roundtrip.mjs` · `pdf.js` 는 사용자 Mac 터미널에서만 돈다.

**챗 컨테이너에서 재는 절차**

```
① device_bash          node scripts/build.js <문서>.json --embed
② device_stage_files   out/html/*.html 하나만 올린다 (자기완결)
③ 컨테이너              npm i playwright · 브라우저는 내려받지 않는다
④ 컨테이너              chromium.launch({ executablePath: '/opt/pw-browsers/chromium-1194/chrome-linux/chrome' })
⑤ 끝나면                node scripts/build.js <문서>.json --link 로 되돌린다
```

**주입 CSS** — 빼면 좌표가 0.42배로 나온다.

```
body{padding:0!important}
.wrap{width:2339px!important;margin:0!important}
.sheet{width:auto!important;height:auto!important;overflow:visible!important;margin:0 0 20px 0!important}
.sheet .page{transform:none!important;margin:0!important}
```

| 재는 것 | 방법 |
|---|---|
| 열 경계 | `.row` 자식의 `offsetLeft` · `offsetWidth` |
| 넘침 | `.bd` · `.col` · `.b` 의 `scrollHeight − clientHeight` |
| 블록 안 빈자리 | `블록 bottom − padding − 마지막 자식 bottom` |
| 회귀 | 쪽마다 PNG 를 떠서 `numpy` 로 픽셀 대조 |

**`--embed` 는 13MB 가 된다.** 폰트 + 그림 base64. 스테이징 한도 안이다.
