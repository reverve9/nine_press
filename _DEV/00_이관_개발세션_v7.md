## §1 새 머신 세우기

**옛 경로는 `/Volumes/BridgeNine/NINE_DEV/PROJECT/NINE_press` 였다.** 외장 볼륨이다.
새 머신에서는 아무 데나 받아도 된다 · **커밋 전부가 원격에 있다.**

```sh
git clone git@github.com:reverve9/nine_press.git
cd nine_press
npm install
npx playwright install chromium        # 관문 셋이 이걸 쓴다
```

**SSH 키를 먼저 세운다.** 이게 빠져 있어서 새 머신에서 `save.sh` 가 커밋만 하고
`Permission denied (publickey)` 로 푸시에서 멈췄다. `gh` 도 없고 키체인에도 없었다.

```sh
ssh-keygen -t ed25519 -C "reverve9@naver.com · <머신이름>" -f ~/.ssh/id_ed25519 -N ""
ssh-add --apple-use-keychain ~/.ssh/id_ed25519
cat ~/.ssh/id_ed25519.pub          # GitHub → Settings → SSH and GPG keys → New SSH key
ssh -T git@github.com              # "Hi reverve9!" 가 나오면 선다
```

`~/.ssh/config` 에 이렇게 둔다.

```
Host github.com
  HostName github.com
  User git
  IdentityFile ~/.ssh/id_ed25519
  IdentitiesOnly yes
  AddKeysToAgent yes
  UseKeychain yes
```

**공개키 등록만 사람이 한다.** 브라우저에 로그인만 돼 있으면 챗 세션이 폼을 채워 등록할 수 있다.
**비밀번호 입력은 챗 세션이 못 한다** · 로그인은 사람이 한다.

**폰트는 내려받지 않아도 된다.** `assets/fonts/*.woff2` **14개가 레포에 커밋돼 있다.**
`scripts/fonts.sh` 는 최초 1회용이고 이제 돌릴 일이 없다.

**서는지 확인 · 이 넷이 다 통과해야 한다.**

```sh
node scripts/기준선.mjs                                    # 205개 · 어긋남 0
node scripts/roundtrip.mjs content/_check/판면기준.json      # 259개 · 불일치 0
node scripts/roundtrip.mjs content/sokcho/실행계획서.json --v3  # 1,012개 · 불일치 0
node scripts/build.js content/_check/판면기준.json --grid    # 14면 · 31KB
```

```sh
npm run dev        # http://localhost:4400 · 사용자가 띄운다
```

## §3 작업 방식 · **이번 세션에서 바뀌었다**

**옛 방식** · 사용자가 `_DEV/prompt/<단계>_구현프롬프트.md` 를 쓰면 그대로 수행.
**새 방식** · 사용자 지시 그대로다.

> 프롬프트 초안을 검토 받을 일은 없고 로컬서버 내가 돌리고 있으니까
> 바로바로 진행하고 나한테 확인 받으면 되고 단 페이즈는 잘 나눠서 가자

| | 규칙 |
|---|---|
| ① | **프롬프트 왕복을 하지 않는다.** 바로 넣고 사용자에게 눈 검사를 받는다 |
| ② | **페이즈를 잘게 나눈다.** 한 번에 하나씩 · 각각 눈으로 판정 가능하게 |
| ③ | **무엇을 볼지 정확히 짚어 준다.** 「몇 면 어디가 어떻게 보이면 통과」까지 |
| ④ | **`git` 을 직접 쓰지 않는다.** `sh scripts/save.sh "메시지" <경로들>` 만 쓴다 |
| ⑤ | **`next build` 를 돌리지 않는다** |
| ⑥ | **dev 서버에 붙지 않는다.** 눈 검사는 사용자가 한다 |
| ⑦ | 표기 · `—` 를 쓰지 않는다. 구분자는 `·` 와 `\|`. 분량은 「쪽」으로 센다 |
| ⑧ | **관문을 통과해야 커밋한다.** §1 의 넷 |

**설계가 논의 중에 바뀐다.** 이번 세션에도 네 번 바뀌었다(§6). 바뀌면 설계 문서를 고치고 이유를 남긴다.

### 4-1. 끝난 것 · `N-글자 b` 머리 뒤 위계 간격

**사용자가 제기한 문제였다.**

> 라벨과 본문 첫 행의 행간이 같으면 가독성이 떨어지지

맞았다. 제목 → 요약 → 본문이 전부 42 로 같아 자리 안이 한 덩이로 뭉쳐 있었다.

**자리 안은 덩이가 둘이다** · 머리(제목 + 요약) 와 몸(문단들).
제목 29 와 요약 26 은 크기 차가 3px 뿐이라 **붙여야 한 덩이로 읽힌다.**
그래서 한 칸은 **요약 뒤**에 쓴다 · `--머리뒤:42px` · 설계 v2 §5-6.

| 안 | 제목 뒤 | 요약 뒤 | 값 | 판정 |
|---|---|---|---|---|
| A 없음(옛) | 0 | 0 | 0줄 | 머리와 몸이 뭉친다 |
| B 제목 뒤 | 42 | 0 | 1줄 | **더 나빴다** · 요약이 본문 첫 문장처럼 붙는다 |
| **C 요약 뒤** | 0 | 42 | 1줄 | **채택** |
| D 둘 다 | 42 | 42 | 2줄 | 제목·요약을 갈라 놓고 값만 두 배 |

**치르는 값** · 자리마다 본문 한 줄. G1 · G3 은 21 → 20 · G9 는 9 → 8.
제목 + 요약이 다 붙은 자리의 본문 예산은 **줄 수 − 3** 이다.

**눈으로 볼 것** · `out/html/_위계_비교.html` 12면 · 골격 3 × 안 4.
**01 ~ 04 면이 G9** 이고 문안이 A 예산에 꽉 차 있다. 02(B) 에서 요약이 본문에 붙고
04(D) 에서 마지막 줄이 잘린다. **03(C) 이 지금 넣은 값이다.**

## §5 관문과 도구

```sh
node scripts/기준선.mjs [문안.json]      42 격자 전수 검사 · 어긋나면 종료 코드 1
node scripts/roundtrip.mjs <문안> [--v3] 제자리 편집 왕복 검사
node scripts/build.js <문안> [--v3] [--grid] [--embed] [--link]
sh scripts/save.sh "메시지" <경로들>     커밋 + 푸시
```

| 깃발 | 뜻 |
|---|---|
| `--v3` | **봉인한 12칸 트랙 렌더러**로 그린다 · 옛 문안 39쪽 전용 · `render/_v3/봉인.md` |
| `--grid` | 기준선 자 42px 를 켠다 · 검사용 · 출력에 안 나간다 |

**개발 서버에서 자를 보려면** 사이드패널의 **「기준선」** 칩을 누른다 · 단축키 `⌘\`.
문안에 `"기준선": true` 가 있으면 켠 채로 열린다(`판면기준.json` 에 들어 있다).
**패널이 정본이다** — 문안 값과 무관하게 껐다 켰다 할 수 있다.

자는 `rules/page.css` 의 `.wrap.bl .bx:before` 하나뿐이다. 앱은 클래스만 껐다 켠다 ·
판면을 다시 그리지 않으므로 **제자리 편집 중에 눌러도 커서가 안 날아간다.**

**옛 12칸 트랙 격자(`.gridov`)는 걷어냈다.** 걸음 `92.73975` 도 `.row` 도 새 체계에 없어
켜 봐야 엉뚱한 선만 그렸다.

## §7 함정

| | 무엇 |
|---|---|
| ① | **`roundtrip` · `build` 가 옛 문안에서 깨진다.** `--v3` 를 붙인다. 안 붙이면 `구성에 띠가 없다` |
| ② | **`save.sh` 에 한글 파일 경로를 못 넘긴다.** macOS 가 NFD 자모 분해형으로 저장해 NFC 문자열과 안 맞는다. **에러 없이 「바뀐 것 없음」만 찍는다.** 상위 디렉터리 이름(`content` · `rules` · `_DEV`)으로 넘긴다 |
| ③ | **문안 파일을 밖에서 고치면 개발 서버를 재시작해야 반영된다** |
| ④ | **「제목」이 두 뜻이다.** `면.제목` 은 헤더 밴드(폭 2179 · 안 접힌다) · `자리.제목` 은 자리 안이다. **섞어 재서 틀린 값을 한 번 냈다** · 면 제목 39 · 블록 제목 6 이 맞다 |
| ⑤ | **`--문단사이` 는 0 또는 42 만 쓴다.** 21 은 홀짝으로 엇갈린다 |
| ⑥ | **라벨(`.lb`)은 한 줄 전제다.** 두 줄이면 70 이 되어 격자가 깨진다 |
| ⑦ | **메인카피는 한 줄이다.** 두 줄이면 카피 존 156 을 57 넘친다 · 64px 에 **34자** 한계 |
| ⑧ | **논지 밴드는 여유가 0 이다.** 45 × 1.2 = 54 로 딱 맞는다 |
| ⑨ | **가로 `split()` 은 고치지 않는다.** 「키노트 세팅 그대로다」가 붙어 있다. 세로 `rows()` 에는 안 붙어 있어 이번에 스냅했다 |
| ⑩ | **검사 도구를 먼저 의심한다.** 이번에 두 번 · 자리별 여백을 안 읽어 거짓 어긋남 · 새 계층을 안 세어 덩이 누락 |
| ⑪ | **크롬 확장이 안 붙는다.** 브라우저 교차검사는 **Playwright 로 한다** · 레포에 이미 있다 |
| ⑫ | **비교본은 문안을 예산에 꽉 채워야 한다.** 안 채우면 안 넷이 전부 「안 넘침」으로 나와 **치르는 값이 안 보인다.** `N-글자 b` 에서 두 번 다시 짰다 |
| ⑬ | **한 줄 글자 수를 `폭 ÷ 24` 로 어림하면 30% 적게 나온다.** 전각 가정이라 그렇다. 실제 산문은 평균 19~20px · **632px 에 34자 · 2113px 에 107자**. 설계 §5-2 표는 일부러 보수적으로 둔 값이지 틀린 값이 아니다 |
| ⑭ | **임시 검사 스크립트를 `/tmp` 에 두면 `playwright` 를 못 찾는다.** ESM 해석이 파일 위치 기준이라 그렇다. **레포 안 `out/` 에 둔다** · `out/` 은 `.gitignore` 라 딸려 들어가지 않는다 |
| ⑮ | **`save.sh` 는 푸시가 막혀도 커밋은 한다.** SSH 키가 없으면 커밋 뒤 `Permission denied (publickey)` 만 찍고 끝난다. **커밋은 살아 있으니 키를 세운 뒤 `git push` 만 하면 된다** · §1 |
| ⑯ | **크롬 확장은 붙는다** · ⑪ 은 옛 머신 이야기다. 이 머신에서 GitHub 폼 작성까지 됐다 |
| ⑰ | **`display:inline-block` 조각이 격자를 깬다.** `{TBD}` 배지가 행간 42 를 물려받아 44 가 되어 그 줄만 2px 밀렸다. **새 인라인 조각에는 제 행간을 준다** · 설계 §5-8 |
| ⑱ | **문단 안 줄바꿈은 된다.** Enter → `<br>` → JSON `\n` → 다시 `<br>`. **못 하는 건 문단을 나누고 합치는 것**이고 그건 B 페이즈다 |
