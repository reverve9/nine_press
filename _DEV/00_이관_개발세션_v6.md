## 7. 함정 — 이번 세션에서 어시스턴트가 실제로 밟은 것

**v5 §7 ①~⑧ 과 v4 §8 은 그대로 유효하다.** 아래는 이번에 새로 밟은 것이다.

| | 무엇 | 어디서 |
|---|---|---|
| ① | **`—` 를 쓰지 마라.** 표기규칙 v2 §2. 채팅 · 문서 · SVG 전부 해당한다. 사용자가 한 번 정한 규칙이다 | 구조도 · 체크리스트 · 채팅 전반 |
| ② | **분량은 「쪽」으로 센다.** 「면」이라 쓰지 않는다. 표기규칙 v2 §8 | 채팅 전반 |
| ③ | **협상 입장을 지어내지 마라.** 내부 문서라도 근거는 문서 원문이어야 한다. 「접수 모수가 배분의 전제」 「중도 이탈 대응의 축」 전부 원문에 없다 | 체크리스트 v1 |
| ④ | **macOS 파일명은 NFD 다.** `git diff -- content/sokcho/실행계획서.json` 은 pathspec 이 안 걸린다. **디렉터리로 건다** | git diff |
| ⑤ | **`device_commit_files` 경로에 한글을 이스케이프로 넣지 마라.** `캐`(캐) 를 `캡`(캡) 으로 잘못 써 `assets/캐처/` 가 생겼다. **챗은 폴더를 못 지운다** | 구조도 커밋 |
| ⑥ | **`git log -L` 의 「file has only N lines」는 커밋본 기준이다.** 작업본 줄 수와 다르면 그 차가 미커밋분이다. 이것으로 gn 238줄이 갈렸다 | page.css |
| ⑦ | **눈대중으로 「크기가 다르다」고 말하지 마라.** 13쪽 그림이 작아 보였으나 실측은 자리와 정확히 같았다. 캡처 자체의 여백이었다 | 그림 삽입 |
| ⑧ | **엑셀 열 폭을 화면 기준으로 잡지 마라.** A4 가로 인쇄 폭에 맞춘다 | 체크리스트 |

## 8. 검사 절차 — v5 §8 그대로. 이번에 확인된 것만 보탠다

**챗 쪽 VM(`device_bash`)에는 playwright 브라우저가 없다.** `roundtrip.mjs` · `pdf.js` 는 사용자 Mac 터미널에서만 돈다.

**챗 컨테이너에서 재는 절차**

```
① 로컬(device_bash)   node scripts/build.js <문서>.json --embed
② device_stage_files  out/html/*.html 하나만 올린다 (--embed 라 자기완결)
③ 컨테이너            npm i playwright · 브라우저는 내려받지 않는다
④ 컨테이너            chromium.launch({ executablePath: '/opt/pw-browsers/chromium-1194/chrome-linux/chrome' })
⑤ 끝나면              node scripts/build.js <문서>.json --link 로 되돌린다
```

**주입 CSS 는 v5 §8 그대로.** 빼면 좌표가 0.42배로 나온다.

**`--embed` 는 13MB 가 된다.** 폰트 + 그림 base64. 스테이징 한도 안이다.

### 9-1. P2.5-b 프롬프트를 쓰기 전에 정할 것 다섯
