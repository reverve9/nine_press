## 4. 키노트 웹 작업법 — **이 세션에서 실측한 것. 다시 시험하지 말 것**

### 4-1. 되는 것

| | 방법 | 왕복 |
|---|---|---:|
| 위치·크기 지정 | 정렬 패널에 X · Y · 너비 · 높이 **수치 입력** | 1 |
| 모서리 반경 | 정렬 패널 수치 | |
| 텍스트 입력 | 블록 더블클릭 → `cmd+a` → 타이핑. **여러 블록을 한 배치에** | 1 |
| 표 채우기 | 첫 셀 클릭 → `값 [Tab] 값 [Tab] …` | 1 / 표 |
| 개체 복사 | `cmd+C` → `cmd+V`. **서식·폰트 그대로** | 1~2 |
| 슬라이드 복제 | 네비게이터에서 슬라이드 선택 → `cmd+C` → `cmd+V` | 1 |
| 스타일 복사 | `⌥⌘C` / `⌥⌘V` | |

### 4-2. 막히는 것 — 우회법까지

| 문제 | 우회 |
|---|---|
| **표 패널의 「행 / 열」 숫자 필드가 안 먹는다.** 스피너도 안 됨 | **행 핸들 우클릭 → 「선택한 행 삭제」.** 열도 같다 |
| **마지막 셀에서 `Tab`을 누르면 행이 새로 생긴다** | 마지막 셀에서 Tab을 누르지 않는다. 실수하면 그 행을 우클릭 삭제 |
| **셀에서 `Escape`를 누르면 그 셀 입력이 취소된다** | 끝은 `Tab` 또는 다른 셀 클릭으로 닫는다 |
| **행 선택 후 `Delete`는 내용만 지운다** — 행이 안 없어짐 | 우클릭 메뉴를 쓴다 |
| **텍스트 블록 너비는 처음에 회색(자동)** | 가로 핸들을 한 번 끌면 고정되고 수치 입력이 열린다. **높이는 계속 자동** |
| **Paperlogy · Pretendard 가 웹 폰트 목록에 없다** | 사용자가 **데스크탑 앱에서** 지정해 두면 웹 편집 후에도 유지된다 — **확인 완료** |
| 채팅에서 복사해 붙이면 회색 배경이 딸려간다 | `⌥⇧⌘V` (붙여넣고 스타일 일치시키기). 제가 타이핑하면 안 생긴다 |

### 4-3. 화면 좌표 환산

슬라이드 좌표 → 화면 좌표는 선형이다. 박스 두 개를 클릭해 정렬 패널 값을 읽고 배율·원점을 구하면, **이후엔 스크린샷 없이 계산으로 클릭할 수 있다.**

### 4-4. 동시 편집 주의

**제가 만지는 동안 사용자는 데스크탑 앱을 닫아 둔다.** 읽기만 하면 충돌은 안 나지만, 앱이 오프라인이었다가 올라오면 충돌본이 생긴다. 자동 저장이라 저장 버튼은 없다. 되돌리기는 `⋯ → 모든 버전 탐색`.

## 5. 역할 분담 — 사용자가 정한 구도

```
① 콘텐츠 확정 (나 ↔ 사용자)
② 판면 가이드 정리 (사용자)          ← 05면이 기준. 이미 있음
③ 페이즈별 텍스트 일괄 입력 (나)
④ 앱에서 1차 확인 · 워싱 (사용자)  ‖  같은 시간에 다음 페이즈 콘텐츠 확정 (나)
⑤ 반복
```

### 5-1. 경계

| | 담당 |
|---|---|
| 판면 · 격자 · 조판 · 디자인 · 스타일 통일 | **사용자.** 내가 정하지 않는다 |
| 콘텐츠 · 텍스트 입력 · 좌표 산출 · 정렬 수치 적용 | **나** |
| 새 구조(간트 · 다이어그램 · 화면 캡처 배치) | **사용자** |

**값을 넣는 건 나, 기준을 정하는 건 사용자.** 이 선을 넘지 않는다.

### 5-2. 04면 실측 — 판면까지 내가 만들 수 있다

슬라이드 복제 → 헤더 3건 → 라벨 5건 → 목록 3건 → 표 2개 = **왕복 15회.**
비용은 전부 표에서 났다. **표 없는 면은 5~6회.**

**04면에 아직 안 넣은 것** — 기초 현황 조사 아래 주석(「개선 세 항목이 심사 근거」), 산출과 연결 목록 3줄 + 서식 표. 새 텍스트 블록이 필요해 남겨 뒀다.

- **한 면에 박스 6개를 넘지 않는다.** 넘치면 덜어낸다. **활자를 키워 채우지 않는다**
- 허위·과장 금지 / KB 브랜드 어휘 금지 / 배점·평가 항목 노출 금지

## 9. 로컬 작업 파일 — 새 머신에서 재현

`_DEV/_docu/html/` 에 최신본이 있다. HTML을 다시 만들 때 필요한 것:

```bash
# 폰트
for w in 2ExtraLight 4Regular 6SemiBold 7Bold 8ExtraBold; do
  curl -sfL -o "fonts/Paperlogy-$w.woff2" \
    "https://raw.githubusercontent.com/fonts-archive/Paperlogy/main/Paperlogy-$w.woff2"; done
npm pack pretendard@1.3.9 --silent >/dev/null && \
  tar xzf pretendard-1.3.9.tgz -C fonts --strip-components=1 package/dist/web/static/woff2
```

- CSS 원천은 프로젝트의 `claude/사업장운영시뮬레이션_빌드스크립트.py` 안 `CSS = '''…'''` 블록

- 측정은 playwright — `.page` 기준 `getBoundingClientRect()`. **1px = 1pt**

## 10. 이 세션에서 시간을 낭비한 지점 — 반복하지 말 것

1. **컨펌 없이 형식을 가정했다.** 판면·산출 형태를 안 묻고 목차부터 짰다가 되돌렸다 → **형식 → 목차 → 내용 순서**
2. **범위를 임의로 넓혔다.** 사용자가 「조판·디자인은 내가 한다」고 했는데 격자안을 내가 정하려 했다
3. **흰 글자를 못 알아봤다.** 텍스트 입력이 안 되는 줄 알고 30분 헤맸다. 실제로는 처음부터 들어가고 있었다 → **안 보이면 색부터 의심한다**
4. **표 기능을 과소평가했다.** 「셀 단위라 느리다」고 했는데 Tab 이동을 계산에 안 넣었다. 실제로는 표 하나를 한 배치에 채운다
5. **`head`로 파이프를 잘라 낡은 PNG를 보고 겹쳤다고 오판했다**
6. **20문항 표가 밀렸다고 잘못 지적했다.** 화면을 제대로 안 봤다
